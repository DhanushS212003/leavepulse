# LeavePulse

LeavePulse is a full-stack leave management application that enables organizations to manage employees, leave types, leave balances, leave requests, approvals, and holidays.

### Features

- Employee and organization management
- Role-based access for HR, Managers, and Employees
- Leave type and leave balance management
- Financial year-based leave allocation
- Automatic approval for HR leave requests when sufficient balance is available
- Holiday management
- JWT-based authentication

### Technology Stack

**Frontend**

- React
- TypeScript
- Vite
- Axios

**Backend**

- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
